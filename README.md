# 🎮 존댓말 차원 탐험대 (Manner Dimension Explorer)

초등학교 3학년을 위한 웹 기반 국어 게이미피케이션 학습 플랫폼입니다.

## 🌟 주요 특징 및 기능

1. **🎨 2D 픽셀 아트 레트로 비주얼 & 크롬북 최적화 (가로 모드)**
   - 상단 GNB 한 줄 제목 고정 및 콤팩트 종료 버튼
   - 키보드 타자 없이 터치/마우스 클릭 및 어절 블록 조립 UI

2. **🔑 8단계 구체적 로그인 & 교사 승인 시스템**
   - **최종 관리자 (Super Admin)**: `keriskeris0106@gmail.com` 지정 계정. 가입 신청한 교사 계정을 승인/거절.
   - **교사 (Teacher)**: Google 로그인 ➔ 가입 신청 (학교, 학년 1~6, 반 1~10, 클래스명) ➔ 승인 후 고유 클래스 초대 코드 기반 학반 관리 및 개별 리포트 인쇄/PDF 출력, 커스텀 퀘스트 작성.
   - **학생 (Student)**: 클래스 초대 코드 + 닉네임 금지(실명) + 학년/반 선택 접속. 자동 로그인 및 세션 복구 지원.

3. **🗺️ 핵심 콘텐츠 3종**
   - **월드 퀘스트 (스토리 모드)**: 5개 테마 월드(시끌벅적 우리 마을, 신비한 동화 월드, 삐뽀삐뽀 미래 병원, 거꾸로 초등학교, 조선시대 타임슬립) 및 세부 장소. 5턴 메신저 UI 대화, 안전한 AI 하이브리드 대화 엔진.
   - **바른말 수호대 (서바이벌 랭킹전)**: 하트(목숨) 3개, 5분 제한시간, 어절 블록 조립. 오답 시 원래 위치 흩어지기. 하트 0개/시간 소진 시 게임 오버되며 **틀렸던 문제 목록 오답 노트를 팝업으로 요약**.
   - **명예의 전당 (리더보드)**: 최고 연속 맞힌 문제 수 기록 저장.
   - **차원 대통합 모드**: 5개 마스터 배지 해금 후 무한 조합 퀘스트 진행.

4. **🎖️ 특수 어휘 배지 & 칭호 시스템**
   - `진지 배지`, `연세 배지`, `성함 배지`, `주무시다 배지`, `댁 배지` 및 월드 마스터 배지 5종.
   - 배지 수집 개수에 따른 칭호 자동 부여 (`🌱 새싹 탐험대` ➔ `🗡️ 바른말 수호기사` ➔ `🛡️ 예의범절 마스터` ➔ `👑 존댓말 수호대장` ➔ `🌌 차원 대마법사`).
